# Grocery Billing System

## Description

A Python-based Grocery Billing System for creating and managing
customer grocery bills.

## Features

- Create Bill
- Add Multiple Grocery Items
- Calculate Total Amount
- View All Bills
- Search Bill
- Delete Bill
- JSON File Storage
- Date and Time
- Exception Handling

## Concepts Used

- Python OOP
- Classes and Objects
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements
- JSON File Handling
- Exception Handling

## How to Run

```bash
python main.py
