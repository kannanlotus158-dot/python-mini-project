# Inventory Management System

## Description

A Python-based Inventory Management System for managing
products, stock, prices, and sales.

## Features

- Add Product
- View Products
- Search Product
- Update Product
- Sell Product
- Delete Product
- Stock Management
- Calculate Sale Amount
- JSON File Storage
- Exception Handling

## Concepts Used

- Python
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements
- JSON File Handling
- Exception Handling

```bash
python main.py
