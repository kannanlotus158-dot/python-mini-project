# Quiz / Exam Management System

## Description

A Python-based Quiz and Exam Management System for creating
questions and conducting quizzes.

## Features

- Add Question
- View Questions
- Start Quiz
- Calculate Score
- Calculate Percentage
- Pass/Fail Result
- Delete Question
- JSON File Storage
- Exception Handling

## Concepts Used

- Python OOP
- Classes and Objects
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements
- JSON File Handling
- Exception Handling

## How to Run

```bash
python main.py
