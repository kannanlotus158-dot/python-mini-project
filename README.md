# Bank Account Management System

## Description

A simple Python-based Bank Account Management System.
It allows users to create accounts, deposit money, withdraw money,
check balance, search accounts, display accounts, and delete accounts.

## Features

- Create Bank Account
- Deposit Money
- Withdraw Money
- Check Balance
- View Account Details
- Search Account
- Display All Accounts
- Delete Account
- JSON File Storage
- Exception Handling

## Concepts Used

- Python Classes and Objects
- Functions
- Dictionaries
- JSON File Handling
- Exception Handling
- Loops
- Conditional Statements

## How to Run

```bash
python main.py
