# Expense Tracker

## Description

A Python-based Expense Tracker for recording and managing
daily expenses.

## Features

- Add Expense
- View Expenses
- Calculate Total Expenses
- Search Expense
- Delete Expense
- Date Tracking
- JSON File Storage
- Exception Handling

## Concepts Used

- Python OOP
- Classes and Objects
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements
- JSON File Handling
- Exception Handling

python main.py
